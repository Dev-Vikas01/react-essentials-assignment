# React Essentials Assignment

## Portfolio Card Application

This project is built using React + Vite.

### Features

- Dynamic Portfolio Card
- Multiple User Profiles
- Dark/Light Theme Toggle
- Dynamic Skills Rendering
- Like Counter
- Profile Navigation
- Responsive UI
- Smooth Animations

### Technologies Used

- React
- Vite
- JavaScript
- CSS3
